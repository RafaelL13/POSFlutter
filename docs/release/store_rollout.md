# Despliegue por tienda/sucursal

1. Despliegue backend central, SQL Server, HTTPS, secretos y backups.
2. Cree o valide negocio y sucursal.
3. Genere enrollment de dispositivo con vigencia controlada.
4. Verifique firma/checksum e instale el APK.
5. Configure el endpoint HTTPS mediante el artefacto destinado al ambiente.
6. Enrole el dispositivo y realice login por rol.
7. Ejecute sincronización inicial.
8. Pruebe operación offline y reinicio.
9. Realice una venta/caja controlada.
10. Reconecte, sincronice y confirme ausencia de duplicados.
11. Capacite responsables en backup, atención de sync y rollback.

No cargue usuarios demo ni contraseñas predeterminadas en producción.
